# Architecture decision records

One file per decision: `NNN-short-title.md`. Numbers 001–010 follow the ten key design
decisions in doc 02 (§Key design decisions). Later ADRs (dependencies, deviations,
implementation choices) start at 011. An ADR is never edited after it is accepted except to
mark it superseded; a new ADR replaces it.

Format: Status · Context · Decision · Alternatives rejected · Consequences · Spec references.
